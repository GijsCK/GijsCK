# About me👋

My name is Gijs and I'm a Master's student in **Quantum Information Science & Technology**, a joint programme between TU Delft and Leiden University.

I have Bachelor's degrees in **Computer Science** and **Information Science**, and my interests include quantum computing, quantum algorithms, machine learning, and software development.

## 🔬 Current projects

### [Quantum Circuit Representation](https://github.com/GijsCK/Quantum-Circuit-Representation)
An interactive browser application for exploring quantum states, gates, and circuits. It includes Bloch sphere visualizations, single- and two-qubit operations, and demonstrations of entanglement.

### LaTeX Calculator
A personal programming project to develop a calculator that parses LaTeX mathematical expressions and evaluates them numerically. I'm implementing it independently to strengthen my programming and software design skills.

## 📚 Research and previous projects

### [Resource-Centric Next Activity Prediction](https://github.com/GijsCK/Resource-Centric-NAP)
A research project investigating how different sequence encoding and embedding methods affect next activity prediction on process event logs.

The project compares seven encoding approaches, including Word2Vec, Doc2Vec, and BERT-based representations, using Random Forest and LightGBM classifiers.
